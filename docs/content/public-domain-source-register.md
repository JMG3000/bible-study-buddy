# Public-Domain Source Register

Last reviewed: 2026-06-04.

## Approved Source Posture

- Seed lessons use original Bible Study Buddy lesson-plan text.
- Seed lessons store Scripture references only, not full Bible passage text.
- No copyrighted study notes, commentary, devotional text, or lesson outlines are copied into seed content.

## Public-Domain Bible References

| Source | Public-domain note | Use in this project |
| --- | --- | --- |
| World English Bible | The official World English Bible site describes WEB as a public-domain modern English translation. Source: `https://worldenglish.bible/`. | Acceptable for future quoted Scripture text if attribution/edition notes are added first. |
| King James Version | KJV is generally public domain in the United States; UK Crown rights can apply in the United Kingdom. Reference: `https://en.wikisource.org/wiki/Bible_(King_James)`. | Acceptable for US-focused public-domain reference checks, but avoid full-text quoting until edition/use context is documented. |

## Seed Content Rule

For now, use references such as `Luke 11:1-13` and write original lesson objectives, questions, activities, and prayer prompts.
